# Aanya Rao Portfolio

A responsive one-page personal portfolio built with semantic HTML, modern CSS, and a small amount of JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with a local development server such as VS Code Live Server.

## Included

- Semantic `header`, `nav`, `main`, `section`, `article`, and footer structure
- Responsive CSS Grid and Flexbox layouts
- Mobile navigation menu and keyboard-friendly focus states
- Smooth anchor navigation with a reduced-motion fallback
- About, skills, selected projects, and contact sections

## Customize

Replace the example name, bio, email address, social links, and project descriptions in `index.html`. The colors and typography are defined at the top of `style.css` for quick restyling.
